## What `ActionController::Live` costs a page with no Suspense (`/plain`, production)

Throughput is three 4-second `wrk` runs after a warm-up, on a machine doing other things: read the spread between runs before reading a difference between rows.

- **Live on every action**: the action runs on the other thread; document 462 / 474 / 473 req/s, Flight 658 / 662 / 641 req/s (wrk, 3 runs of 4 s, 3 connections); document headers: `cache-control: no-cache`, `transfer-encoding: chunked`; Flight response: no ETag; `/slow` still sends its shell before the gate opens = true
- **Live chosen per action, `plain` left out**: the action runs on the request thread; document 487 / 497 / 503 req/s, Flight 708 / 695 / 704 req/s (wrk, 3 runs of 4 s, 3 connections); document headers: `cache-control: max-age=0, private, must-revalidate`, `etag: W/"03d46e8d56efffb7d9562e56ba3d39ee"`, `content-length: 978`; Flight response: ETag sent, `If-None-Match` → 304; `/slow` still sends its shell before the gate opens = true
- **no Live (lazy body)**: the action runs on the request thread; document 477 / 484 / 483 req/s, Flight 690 / 692 / 686 req/s (wrk, 3 runs of 4 s, 3 connections); document headers: `cache-control: max-age=0, private, must-revalidate`, `etag: W/"508b8516cb6d3c17051e8901afbf9886"`, `content-length: 978`; Flight response: ETag sent, `If-None-Match` → 304; `/slow` still sends its shell before the gate opens = true

## What a middleware scoped around the request (`/mw`)

The middleware wraps the app in `I18n.with_locale(:pt)` and in `ActiveRecord::Base.connected_to(role: :writing, prevent_writes: true)`. The block waits at a gate, which opens only after the client has the response's headers: the middleware has returned by then.

- **0.0.19 with Live (today)**, `/mw` as the server's first request — shell: locale `pt`, writes prevented, the middleware's thread variable `none`; block: locale `pt`, writes prevented. A page with no such middleware, right after: locale `pt`
- **0.0.19 with Live (today)**, `/mw` after another page (locale `en`) has run — shell: locale `en`, writes prevented, the middleware's thread variable `none`; block: locale `en`, writes prevented
- **prototype, Live**, `/mw` as the server's first request — shell: locale `pt`, writes prevented, the middleware's thread variable `none`; block: locale `pt`, writes allowed. A page with no such middleware, right after: locale `pt`
- **prototype, Live**, `/mw` after another page (locale `en`) has run — shell: locale `en`, writes prevented, the middleware's thread variable `none`; block: locale `en`, writes allowed
- **prototype, lazy body**, `/mw` as the server's first request — shell: locale `pt`, writes prevented, the middleware's thread variable `set`; block: locale `en`, writes allowed. A page with no such middleware, right after: locale `en`
- **prototype, lazy body**, `/mw` after another page (locale `en`) has run — shell: locale `pt`, writes prevented, the middleware's thread variable `set`; block: locale `en`, writes allowed
